# Hardware

Printed parts and mechanics of the devices around the home monitor.

```
hardware/
├── requirements.txt       python packages for the CAD scripts
└── feeder/                cat feeder
    └── iris/              NEMA 17 iris valve that portions the kibble
```

Planned next to it: the feeder hopper and stand, the electronics enclosure (ESP32 + TMC2209), a camera mount for the ESP32-CAM, and the parts of the heating control.

## How the designs are kept

Each design is a **parametric Python script** ([build123d](https://github.com/gumyr/build123d)) with its dimensions at the top, so a change is a readable diff and every part follows from the same numbers. Next to it, committed and regenerated by the script:

* `stl/`: every part in its print orientation, for the slicer (Bambu Studio, Cura, PrusaSlicer)
* `step/`: every part in its assembled place and the whole assembly, to open in Fusion, Onshape or FreeCAD
* `images/`: what the README shows

A design that moves to Fusion keeps its `.f3d` export and STEP files in a `fusion/` folder next to the script; from then on those are the source.

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r hardware/requirements.txt
cd hardware/feeder/iris && python iris.py
```

build123d needs Python 3.10 to 3.12 (its OpenCascade kernel has no wheels for newer versions yet).
